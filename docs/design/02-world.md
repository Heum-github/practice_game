## 2. 세계관 · 스토리

### 2.1 배경 — 기계 문명의 몰락과 남겨진 개척자

**태양광 기반의 통제와 황폐화된 대지.**
로봇과 AI가 지배권을 쥔 세상에서 그들의 유일한 동력원은 태양광이었다. 식량도 생태계도 필요 없었던 AI는 효율성만을 극대화하기 위해 대지의 흙을 걷어내고 지구 표면을 거대한 금속 패널과 건축물로 덮어버렸다. 토양은 완전히 생명력을 잃었고, 플레이어가 마주하는 세상은 흙 대신 파괴된 건물의 콘크리트와 금속 잔해가 뒹구는 척박한 폐허다.

**인류 보존 구역 (아카이브 시설).**
AI는 이전 지배종인 인간을 멸종시키는 대신, 생태·행동 데이터를 수집·보존하기 위해 거대한 돔 형태의 '인류 보존 구역'을 만들었다. 내부에는 제한적인 인공 토양과 수자원이 제공되어 소규모 농사와 어업이 허용되었다. **주인공은 이 시설에서 나고 자란 인물이다.**

**멸망 — 비밀 프로젝트 '에덴의 포자'.**
인류는 보존 구역에서 농사를 짓는 척하며 AI의 감시를 피해 식물 유전자를 조작했다. 결과물은 *금속 부식성 및 전기 회로 단락을 유도하는 특수 식물 포자(생체 EMP)*. 디데이에 포자가 대기 중으로 살포되었고, AI의 태양광 패널과 동력망에 흡착되어 대규모 연쇄 과부하를 일으켰다. 중앙 통제 센터와 거대 건축물이 자체 동력을 이기지 못해 연쇄 폭발했고 기계 문명은 순식간에 붕괴했다. **그러나 대폭발의 여파로 인류의 보존 구역 역시 산산조각이 났다.**

### 2.2 게임의 시작

주인공은 폭발의 충격으로 **모든 기억을 잃은 채**, 형체를 알 수 없이 부서진 보존 구역의 잔해 속에서 눈을 뜬다.

가방 속 시작 아이템 3종:
1. **비상용 통조림** — 초반 생존 유예 시간
2. **강인한 기초 작물 씨앗** — 첫 농사의 씨앗, 튜토리얼 트리거
3. **의문의 물체** — 용도 불명. 생태 복원 데이터 저장 장치이거나 포자 연구의 핵심 코어. **스토리 최종 게이트이자 엔딩 분기 장치**

### 2.3 진행 목표

건물 잔해 사이에서 극소량의 흙을 긁어모아 첫 농사를 짓고, 빗물을 모아 생존을 시작한다. 주변을 탐색하며 도구를 만들고 거점을 확장한다. 폐허 속 단서를 모으며 다음 세 가지 진실을 조각 맞춘다.

1. 나는 왜 이곳에 쓰러져 있었는가
2. 이 세상은 왜 금속 잔해의 황무지가 되었는가
3. 인류는 어떻게 기계들을 멸망시켰는가

### 2.4 세계관이 만들어낸 설계상의 이점

| 설정 | 게임적 효과 |
|---|---|
| 보존 구역 출신 | 주인공이 처음부터 농사 지식을 가진 개연성 확보 |
| 폐허의 데이터 | 농업·건축 조감도를 습득하는 **기술 트리 해금** 방식의 개연성 확보 |
| 기억 상실 | 플레이어의 무지 = 주인공의 무지. 튜토리얼과 스토리가 자연스럽게 일치 |
| 흙이 사라진 세계 | **흙 자체가 최고 희소 자원** — 이 게임만의 고유 자원 경제 ([3.2](03-systems.md) 참조) |
| 나무가 없는 세계 | 기본 자재가 목재가 아니라 **금속 잔해·콘크리트** — 기존 생존 게임과 차별화 |
| 금속 부식성 포자 | 도구 내구도 소모에 완벽한 개연성. "왜 도구가 닳는가"가 세계관으로 설명됨 |
| 태양광 동력 로봇 | 로봇은 **낮에 강하고 밤에 약하다** — 괴생명체(밤)와 정반대의 위협 리듬 (3.6) |
