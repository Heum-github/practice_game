## 4. 프로토타입 범위 — v0.1 · v0.2 · v0.3 · v0.4 **완료**

> 목적: **"잔해에서 흙을 긁어모아 첫 작물을 수확하고 하루를 버티는 것"** 이 재미있는지 하나만 검증한다.
> 아래 목록에 없는 것은 만들지 않는다.
>
> **v0.1·v0.2 목록이 모두 구현되었다.**
> **v0.3 완료** — 체온·포자병·화톳불 연료·퇴비·계절·환경 악화 곡선.
> **v0.4 완료** — 정착지 등급·생존자 유입·로봇 군단·함정.

**포함** (`[x]` = 구현 완료)
- [x] 200m × 200m 고정 폐허 지형 1개 (무한 생성 없음, 시드 고정)
- [x] 3인칭 카메라 + WASD 이동 + 점프
- [x] 스탯 3종: 체력 / 포만감 / 수분
- [x] 자원 4종: **금속 잔해 / 흙 / 빗물 / 보급 상자(통조림)**
- [x] 인벤토리 12슬롯 + 핫바 6칸, 아이템 스택·섭취
- [x] 제작 3종: 잔해 곡괭이, 물뿌리개, 빗물 집수기
- [x] 농사 전체 사이클 1작물 (흙 확보 → 밭 조성 → 파종 → 급수 → 수확 → 섭취)
- [x] 낮/밤 사이클 (1일 15분)
- [x] 야간 괴생명체 1종 + 근접 공격 1종
- [x] 건축 2종: 잔해 방벽, 화톳불 (둘 다 충돌 있음, 화톳불은 생물을 쫓는다)
- [x] 저장/불러오기 — 백엔드 우선, 오프라인 시 localStorage. 사망 시 완전 초기화
- [x] 시작 아이템 3종 배치 (통조림 / 씨앗 / 의문의 물체 — 물체는 아직 기능 없음)

**기반 작업으로 함께 들어간 것**
- [x] 폐허 절차 생성 (건물·잔해·태양광 패널·철근·돔 파편·쓰러진 첨탑, 약 3,400 인스턴스)
- [x] AABB 충돌 + 공간 해시, 턱 오르기, 경사 미끄러짐, 120Hz 고정 타임스텝
- [x] 벽 회피 3인칭 카메라
- [x] 하늘 셰이더 + 태양·달 조명 + 별 + 시간대별 환경맵
- [x] 대기 중 잔류 포자 연출
- [x] 지형의 흙 함유량 필드 (`sampleSoilRichness`) — 자원 시스템이 바로 쓸 수 있는 상태
- [x] 격자 설치 시스템 (좌클릭) — 건축의 기반
- [x] `E` 하나로 통합된 상호작용 (대상과 소지품을 보고 다음 행동을 자동 선택)
- [x] 작업 모션 — 일구기·채집·수확의 내려찍기, 파종·급수의 손질 동작 (절차적)
- [x] Node 백엔드 (node:http + node:sqlite, 의존성 0) — 세이브 보관 · 시드 발급 · 생존 기록

**v0.2 (성장) 구현분**
- [x] 도구 내구도 + 잔류 포자에 의한 부식 — 쓰지 않아도 삭는다
- [x] 제작 3단계: 맨손 → 작업대 → 조감도 해금
- [x] 작업대 — 곁에 있어야 만들 수 있는 것들이 생긴다
- [x] 보관함 18칸 — 가방 12칸의 압박을 푸는 첫 설비
- [x] 데이터 단말 14곳 — 조감도 데이터를 얻어 새 설계를 연다
- [x] 코팅 곡괭이 — 부식 저항 처리 (내구 160, 부식 1/5)
- [x] 후처리 파이프라인 (GTAO 앰비언트 오클루전 + MSAA) · 매끄러운 지형 셰이딩
- [x] 밭 비옥도 — 땅마다 성장 속도와 수확량이 다르고, 기준 미달인 땅에는 만들 수 없다
- [x] 나침반 · 거점 상태 표시 · 아이템 버리기 — 200m 월드에서 길을 잃지 않게
- [x] 캐릭터·폐허 디테일 보강 (부품 69개, 자갈 5,200, 전선 630마디)
- [x] 폐허(불변)와 지은 것(가변)을 분리한 충돌 집합 — 초기화가 폐허를 건드리지 않는다

**v0.3 (압박) 구현분**
- [x] 체온 — 밤과 비바람에 떨어지고, 해·화톳불·지붕이 되돌린다. 0이면 죽는다
- [x] 포자병 — 대기 잔류 포자가 쌓여 발병한다. 앓으면 느려지고 더 허기지고 체력이 돌아오지 않는다
- [x] 나선형 악화와 그 출구 — 따뜻하고 배부르면 몸이 스스로 이겨낸다 (진행 0.62/일 > 회복 0.42/일)
- [x] 고인 물의 대가를 체력에서 **발병 확률 30%** 로 교체 — "끓여 마실 것인가"를 매번 저울질하게 된다
- [x] 화톳불이 제작 설비가 되었다 — 끓인 물 (갈증 42 · 체온 12 · 포자 없음)
- [x] 포자 억제제 — 작물 3 + 잔해 2. 조감도로 해금하는 첫 번째 설계가 되었다
- [x] 게이지 두 줄 추가 — 체온은 상시, 포자는 쌓였을 때만 나타나고 발병하면 병세 게이지로 바뀐다
- [x] **화톳불 연료** — 마른 풀을 먹여야 탄다. 꺼지면 빛·온기·끓이기가 전부 멈춘다
- [x] 마른 풀덤불 58곳 — 비옥한 땅에만 선다. 연료를 찾는 일이 곧 좋은 땅을 찾는 일이 된다
- [x] 작물을 수확하면 대가 함께 나온다 — 밭이 늘수록 불이 스스로 먹고산다
- [x] 잔량에 따라 사위는 불꽃과 빛 · 나침반의 잿빛 표지 · `꺼진 불` 거점 칩
- [x] **퇴비 더미** — 유기물을 삭혀 흙으로 되돌린다. **흙의 상한이 처음으로 풀렸다**
- [x] 알곡은 마른 풀의 두 배로 삭는다 — "지금 먹을 것인가, 밭을 넓힐 것인가"라는 새 저울
- [x] 며칠 걸리는 설비로 만들었다. 즉석 변환이면 흙은 그냥 작물의 다른 이름이 된다
- [x] **네 계절** — 해빙 · 건기 · 포자철 · 혹한 (계절당 15일, 1년 60일)
- [x] 계절마다 **다른 시스템**을 건드린다 — 체온·포자·성장·건조·날씨 비율·풀 재생
- [x] 해빙기에 마른 풀덤불의 70%가 되살아난다 — 저절로 돌아오는 둘째 자원
- [x] **환경 악화 곡선** — 잔류 포자가 계절마다 +0.09배 (추세 상한 1.6배)
- [x] 농도가 오르면 **포자 노출과 금속 부식이 함께** 빨라진다
- [x] **상승 곡선** — 퇴비로 되살린 흙 한 줌마다 −0.012배. 쉰 줌이면 2년치를 되돌린다
- [x] HUD에 계절(색 구분)과 포자 농도·되살림을 나란히 — 경주가 눈에 보여야 경주다
- [x] 계절색이 안개에 옅게 배어난다 (Sky 뒤에 얹어 시간대 표현을 덮지 않게)


**v0.4 (개척) 구현분**
- [x] **정착지 등급 5단계** — 야영지 · 임시 거처 · 정착지 · 마을 · 개척지
- [x] 조건 셋이 서로 다른 것을 묻는다 — 설비(돌아가는가) · 밭(먹고사는가) · 둘러쌈(지킬 수 있는가)
- [x] **둘러쌈은 격자 물 흘리기로 잰다** — 개수가 아니라 실제로 두른 넓이. 한 곳만 뚫려도 0
- [x] **생존자 유입** — 등급이 부른다. 급수·연료·파종만 하고 새로 짓지는 않는다
- [x] 생존자도 먹는다 (하루 0.6작물/인) — 공짜 노동력이 아니라 밭을 늘려야 할 이유
- [x] **로봇 군단** — 정찰 드론(2등급~) · 중장 보행기(3등급~). 같은 시스템에 `daytime` 플래그로 얹었다
- [x] 낮과 밤의 대칭 완성 — 로봇에게는 **화톳불이 통하지 않는다.** 흐린 날에만 약해진다(×0.45)
- [x] **잔해 함정** — 34 피해 · 4회. 놓는 순간이 아니라 놓은 자리가 실력이다
- [x] 등급이 오르면 보상과 대가를 같이 알린다 — 사람이 모이는 것과 탐지되는 것이 한 줄에서 온다
- [x] **사망 후 기록 계승** ([7장 리스크](07-risks.md)의 완충안) — 조감도·기록 조각·되살린 흙만 넘어간다
- [x] 되살린 흙이 대를 잇는다 — 24줌을 남기고 죽으면 다음 생은 포자 농도 0.80이 아니라 0.57에서 시작한다
- [x] 사망 화면과 오프닝이 회차를 안다 — 죽음이 "다시 시작 버튼"으로만 남지 않게
**명시적 제외 (v0.1에서 만들지 않음)**
- 질병·체온·포자 시스템, 도구 부식
- 무한 월드, 청크 스트리밍, 바이옴
- 로봇 군단, 계절, 환경 악화 곡선
- 장신구, 장비 강화, 기술 트리 해금
- 스토리, 저널, 기록물
- NPC, 정착지 등급
- 사운드, 텍스처, 모델링 에셋 (박스·원기둥만 사용)
- 멀티플레이 관련 일체
