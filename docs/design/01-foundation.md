## 1. 확정 사항

| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹 브라우저 |
| 장르 | 오픈월드 생존 |
| 시점 | 3D · **3인칭** |
| 목표 규모 | 프로토타입 우선 → 재미 검증 후 확장 |
| 조작 | 키보드(WASD) + 마우스 |
| 패배 조건 | 아사 / 질병 / 적의 공격에 의한 사망 |
| 사망 페널티 | **완전 초기화** |
| 클리어 조건 | 안전한 도시 건설 + 사태의 진실 규명 (필수 아님) |
| 진행 구조 | 생존이 주 목표, 스토리는 생존 중 병행 |
| 1일 길이 | **실시간 15분** |
| 플레이 시간 | 제한 없음 |
| 성장 요소 | 무기·장신구 등 장비 강화. 환경 악화로 지속적 도구 수요 발생 |
| 전투 비중 | **20%** — 초반 괴생명체 / 후반 로봇 군단 |
| 멀티플레이 | 싱글 전용 (추후 로컬 협동 검토, 온라인 제외) |
| 저장 | 진행상황 세이브 |
| 아트 | **로우폴리 + 플랫 셰이딩** |
| 기술 | **Three.js + TypeScript + Vite** |

### 핵심 재미 (한 문장)
> 플레이어는 척박한 환경에서 농사를 짓고 필요한 물건들을 수급하며 조금씩 도시를 개척해나간다.
