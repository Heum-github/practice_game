## v0.6 플랜트 — 브라우저 검증 (2026-09-08) · **절반**

확장이 붙어 처음으로 화면에서 봤다. **자동화로 되는 데까지 갔고,
시간이 드는 것들은 못 봤다.** 이유는 아래에 적어둔다.

### 본 것

| 확인 | 결과 |
|---|---|
| 좌클릭으로 세워지는가 | **된다.** 두 대를 세웠다 (−8,−12 / −9,−14) |
| 땅에 제대로 앉는가 | **된다.** 잔해밭 경사에서도 파묻히거나 뜨지 않는다 |
| 퇴비와 구별되는가 | **된다.** 서 있는 기계 + 주황 투입구/배출구 — 실루엣이 갈라진다 |
| 안내가 뜨는가 | `E 잔해를 플랜트에 밀어 넣는다 (0/6)` · `좌클릭 — 토양 재생 플랜트를 세운다` |
| 나침반 표지 | `再` 가 5m 로 뜬다 |
| 빈 플랜트는 조용한가 | `__eden.plants()` → `running: 0` · `noisyHere: false` |
| 드로우콜 | 305~311 (예산 500) — 플랜트 둘을 세운 뒤에도 그대로다 |

### 못 본 것과 그 이유

잔해 투입 → 배기 → 로봇 → 흙 회수. **전부 시간이 드는 것들이라 놓쳤다.**

이 게임은 **커서를 놓으면 시간이 멈춘다**(`Game` 의 `!input.locked → setPaused(true)`).
그런데 자동화가 누른 클릭에서는 포인터 락이 `WrongDocumentError` 로 거절된다
(HUD 의 `시점` 줄에 그대로 뜬다). 그래서 화면은 살아 있는데 **시계가 안 간다** —
1.4초를 눌러야 하는 투입도, 4분 30초가 걸리는 한 줌도 진행되지 않는다.
`__eden.tick()` 으로 프레임을 밀어도 일시정지는 풀리지 않는다.

**사람 손으로는 1분이면 끝난다.** 커서만 잡히면 나머지는 그냥 눌러보는 것이다.

```js
__eden.give('soilPlant', 1); __eden.give('scrap', 60); __eden.setPhase(0.5)
// 좌클릭으로 세우고, E 를 길게 눌러 잔해 6을 밀어 넣는다
__eden.plants()      // running: 1 · noisyHere: true 여야 한다
// 18m 밖으로 걸어 나가서 다시 → noisyHere: false
__eden.setTimeScale(300)   // 한 줌이 4분 30초 → 몇 초로 줄어든다
__eden.world()       // 흙을 꺼내면 restored 가 오른다
```

볼 것 셋 — **배기가 서는가**(도는 동안만), **HUD 에 `플랜트 n대 가동 — 낮에 로봇` 칩이
뜨는가**, 그리고 **낮에 실제로 로봇이 오는가**(흐린 날은 ×0.45 이므로 맑은 날에).

### 남은 숙제

- **성능 예산 A**: 드로우콜만 읽었다. 프레임·로직 CPU 는 포커스가 흔들리는 창에서
  잰 값을 믿을 수 없다 (8.3). 사람이 띄워둔 창에서 다시 잰다
- **회귀 경로 넷**(죽음·세이브·경사·한 해)은 이번에도 못 걸었다
