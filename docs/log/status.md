## 어디까지 왔나

v0.1부터 v0.4까지 구현되었다. v0.3 「압박」에는 체온·포자병·화톳불 연료·퇴비,
네 계절과 환경 악화 곡선이 들어갔고, v0.4 「개척」에는 정착지 등급·생존자·로봇 군단·함정,
그리고 [7장 리스크](../design/07-risks.md)의 완충안인 **사망 후 기록 계승**이 들어갔다.
v0.3.1에서는 실제로 플레이해 나온 문제 열 건을 처리했다 — 버그 다섯(보관함·기록창·스택·버리기·아이콘)과
설계 구멍 다섯(방벽 방향·문·철거·핫바 정리·작물 이름과 요리).

v0.4.1은 성격이 조금 다르다. 절반이 **"고쳤다고 적어둔 것이 플레이어에게는 없는 것과 같았다"**였다 —
방벽 회전도 철거도 들어가 있었지만 어디에도 적혀 있지 않았고 눌러도 화면이 그대로였다.
그래서 방벽이 **옆 칸을 보고 알아서 돌아서게** 하고, 미리보기를 방향대로 눕히고,
뜯을 수 있는 것 앞에서는 철거 안내가 그 자리에 뜨게 했다.
함께 처리한 것 — 길잡이가 시계 패널을 덮던 문제(고정 좌표 → 재서 넘기기),
**시간이 드는 화톳불 조리**, 도감의 세 갈래(식물·조리·땅과 계절),
그리고 죽고 살아나면 문·보관함이 **만질 수 없는 껍데기로 남던** 버그.

이제 검증 질문에 답할 차례다 — 하루를 넘기는 것이 아니라
**한 해를 넘기는 것**이 긴장으로 읽히는가, 그리고 **도시가 커지는 맛이 있는가**.

v0.5 「세계」의 절반이 끝났다. **3막 구조와 종자고**가 들어가면서 이 게임에는
처음으로 **끝까지 가는 길**이 생겼다 — 살아남고, 거점을 세우고, 흙을 되살리고,
그러면 이야기가 열리고, 이야기가 열리면 문이 열린다.

| 층 | 요구 | 열리는 것 |
|---|---|---|
| 생존 | 하루를 넘긴다 | 1막 |
| 개척 | 정착지 등급 2 | 2막 |
| 재생 | 되살린 흙 24줌 | 3막 |
| 결말 | 열 편 전부 | 종자고 열쇠 → 문 → 1,204종 |

앞선 단계들이 저마다 독립된 시스템이었다면, 여기서 셋이 **하나의 문에 걸린다.**
정착지도 퇴비도 이제 "있으면 좋은 것"이 아니라 이야기의 조건이다.

**무한 지형은 접었다.** 숫자를 세어 보니 땅이 모자란 것이 아니라 건널 이유가
없었고, 넓히는 것은 "탐험할 이유가 있는가"에 답하지 않는다. 대신 관측 첨탑을
넣어 질문에 직접 답했다.

다음은 같은 방식의 **폐허 구조물**이다. 첨탑과 종자고가 통했으니 몇 곳 더
세울 수 있는데, 각각 **다른 이유**를 줘야 한다는 것이 요점이다 —
온실 잔해(흙과 풀이 몰려 있다) · 정비 격납고(잔해 산더미, 대신 낮에 로봇이 깨어난다) ·
급수탑(빗물이 대량으로 고여 있다).

**셋 다 세웠다.** 요점은 각각 다른 이유였고, 셋째에 와서야 처음으로 **대가**가 붙었다.

| 구조물 | 자리 | 주는 것 | 대가 |
|---|---|---|---|
| 온실 잔해 | (70, −30) | 흙 22 · 마른 풀 16 | 없다 |
| 급수탑 | (−34, 62) | 빗물 26 | 고인 물이라 끓여야 한다 |
| 정비 격납고 | (26, 72) | 잔해 30 | **등급과 무관하게 낮에 로봇이 깬다** |

셋 다 지형이 정한 조건을 묻지 않는다 — 여기 자원이 있는 이유는 땅이 아니라
**건물**이다. 온실은 깨진 지붕으로 상토가 쏟아진 자리고, 급수탑은 터진 탱크가
고인 자리며, 격납고는 뜯다 만 기계가 쌓인 자리다.

격납고만은 "갈까"가 아니라 **"언제 갈까"**를 묻는다. 로봇은 원래 정착지 등급 2부터
오는데, 여기는 그 문턱을 건너뛴다 — **거점이 아니라 장소가 부르는 것**이다.
야영지뿐인 1일차에도 발을 들이면 낮에 물린다. 잔해는 늘 모자라지만 곡괭이도 없이
들어가면 그냥 죽는다.

### 세우면서 배운 것

넷 다 **화면으로는 절대 안 보이는** 종류였다. 전부 8.3에 옮겨 적었다.

1. **건물은 딱딱한데 땅은 아니다.** 중심 한 점의 높이로 통째로 앉혔더니 기복
   3.3m 인 자리에서 한쪽 벽은 파묻히고 반대쪽은 떴다 — 건물이 아예 안 보이고
   콜라이더는 땅속이라 벽을 통과했다. 평탄한 자리를 찾으려 월드를 다 세어 봤지만
   **가장 나은 곳도 2.33m**였다. 잔해밭에 평지는 없다. 그래서 자리를 옮기는 대신
   뼈대는 수평으로 고정하고 땅에 닿는 것만 제 발밑을 다시 재게 했다.
2. **공간 해시 조회를 겹침으로 읽고 있었다.** `ResourceNodes.blocked()` 가 높이만
   보고 판단해서, 폐허와 구조물 **주변 한 칸(6m)이 통째로 빈 땅**이었다.
   격납고 반경 15m 의 82%가 막힌 것으로 나와 잔해가 한 자리도 안 깔렸다.
3. **그 버그를 고치자 흙이 31에서 50이 됐다.** 흙이 귀하다는 전제가 남의 버그
   수정에 딸려 움직인 것이다. 확률로 개수를 맞추는 일이 두더지잡기가 되어,
   흙·풀·물을 전부 **목표 개수**로 바꿨다 (잔해·보급이 이미 그랬다).
   자리를 정하는 규칙은 가중치로 그대로 살아 있다.
4. **지붕은 콜라이더가 있어야 지붕이다.** 격납고 한복판에서 `shelter: 0` 이
   나왔다 — 지붕이 눈에는 보이는데 비를 맞는다. 덮인 비율도 재 보니 25%였다가
   97%였다가 했다. 51%로 맞췄다.

## v0.6 「결말」 — 첫 조각이 들어갔다

**토양 재생 플랜트.** 로드맵이 나머지 셋의 전제라고 적어둔 그것이다 —
클리어 조건은 읽을 값이 있어야 성립하고, 밀폐 온실의 압박은 되돌리는 쪽이
먼저 서 있어야 답이 된다.

퇴비와 같은 자리에 서지만 되돌리는 것이 다르다. 퇴비는 **키운 것**(마른 풀·알곡)을
삭히고 플랜트는 **부순 것**(잔해)을 되돌린다. 그래서 이 세계에서 가장 흔한 것이
처음으로 가장 귀한 것과 저울에 오른다 — 두를 벽과 되돌릴 흙 사이에서 잔해를 나눠야 한다.

| | |
|---|---|
| 여는 것 | 종자고를 연 것 (조감도가 아니다) |
| 값 | 잔해 40 · **흙 4** — 흙을 만드는 물건을 흙 없이 세울 수는 없다 |
| 환산 | 잔해 6 = 흙 1 · 한 몫에 0.3일 · 한 대가 하루 3.3줌 |
| 대가 | 도는 동안 18m 안이면 **등급과 무관하게 낮에 로봇이 깬다** (격납고와 같은 규칙) |
| 끄는 법 | 넣어둔 몫이 바닥나면 스스로 조용해진다 — 한 통이 1.8일 |

대가를 잔해 유한성이 아니라 **로봇**으로 정한 것이 이번 판단이다. 유한성은
값이지 대가가 아니다 — 값은 낼지를 묻고 대가는 **언제** 낼지를 묻는다.
한 통을 채우는 일이 곧 "며칠을 시끄럽게 둘 것인가"가 되고, 흐린 날에는 로봇이
약하므로(×0.45) 언제 채울지가 날씨를 보는 이유가 된다. 마흔 날 동안 세운
방벽과 묻은 함정이 여기서 처음으로 할 일이 생긴다.

길잡이에도 한 칸을 붙였다. 종자고를 열면 목표가 그냥 사라지던 자리다
([v0.5 플레이테스트](playtest-v0.5.md) D) — 진실이 밝혀지는 것과 그걸로
무엇을 할 수 있는가는 다른 문제다.

### 곡선이 회차 2에서 죽던 것

플랜트를 얹으면서 드러난 것이 하나 더 있다. 되살린 흙(끌어내리는 몫)은
유산으로 대를 잇는데 세계의 나이(밀어올리는 몫)는 매 생 0으로 돌아갔다.
그래서 **한 생에 38줌만 넘기면 다음 생은 1일차부터 곡선 바닥**이었고,
그 뒤로는 무엇을 해도 세계가 같았다 — 3.7의 "두 곡선의 경주"가 회차 2에서 끝난 것이다.
퇴비만으로도 있던 구멍인데, 플랜트 한 대면 12일이면 넘기므로 더는 미룰 수 없었다.

고친 방향은 **세계도 대를 잇게 하는 것**이다. 같은 시드의 같은 폐허이므로
지난 생들이 지나보낸 계절이 사라질 이유가 없다. 이제 하한은 회차와 함께 올라가
결국 88줌(추세 천장)에서 멎는다 — soil-plant 문서가 "영원히 바닥"이라 적어둔 그 값이
비로소 실제로 그 값이 됐다. 계승 화면에는 "이 세계가 난 계절"이 되살린 흙과 나란히 뜬다.

`node scripts/check-curve.mjs` 가 이 회귀를 지킨다 — 한 해를 난 다음 생이
38줌만으로 1일차부터 바닥이면 실패한다.

**확인한 것과 못 한 것.** `npm run typecheck` 통과, 그리고 화면 없이 돌리는
검증 둘이 통과한다 — `scripts/check-plant.mjs`(한 몫이 0.3일에 흙 한 줌인지,
18m 밖에서는 조용한지, 몫이 바닥나면 스스로 멎는지, 가득 찬 채로는 돌지 않는지)와
`scripts/check-curve.mjs`(회차를 넘어서도 곡선이 사는지).
**브라우저로는 절반을 봤다** ([v0.6 플레이테스트](playtest-v0.6.md)) — 세워지고,
땅에 제대로 앉고, 안내가 뜨고, 빈 플랜트는 조용하다. 잔해를 넣은 뒤의 것들
(배기·로봇·흙 회수)은 **시간이 드는 것들이라 자동화로는 못 봤다.** 커서를 놓으면
시간이 멈추는데 자동화가 누른 클릭으로는 포인터 락이 잡히지 않는다.

## 9. 지금까지 만든 것 (현황)

대화를 이어받는 사람이 코드를 뒤지지 않고도 상태를 알 수 있게 적어 둔다.

| 축 | 상태 |
|---|---|
| 보행 | 임상 정상치 표 기반 관절 곡선 · 경사 대응 · 발 접지 IK · 접지 스냅 |
| 캐릭터 | 실제 인체 비율(1.78m) · 타원 단면 팔다리 · 장비만 각진 대비 |
| 지면 | 정점 색 + 코드로 구운 색/노멀/거칠기 맵(3m 타일) |
| 물체 | 흙·잔해·웅덩이·보급상자·기록단말 모두 실물 구조. 웅덩이는 잔물결 + 프레넬 반사 |
| 작물 | 새싹·잎·이삭 3단계 형상 |
| 폐허 | 층마다 창(1,083) · 노출 철근(899) |
| 자원 | 흙 희소 + 시작점 주변 고갈 / 빗물은 12군집 64개 |
| 인벤토리 | 핫바 = 아이템 배정표 · SVG 아이콘 · 툴팁 · × 로 해제 |
| 소리 | Web Audio 합성 (발소리·타격·피격·설치·바람·불) · M 음소거 |
| 길잡이 | 25단계 목표를 한 번에 하나씩. 마지막은 종자고를 연 **다음**이다 |
| 날씨 | 맑음·비·먼지폭풍. 안개·조명·소리·농사에 모두 걸린다 |
| 전투 | 히트스톱 0.07초 + 생물 움찔 자세 |
| 생물 | 세 종류 — 스토커(정면) · 무리(수) · 중장갑(맷집, 3일차부터) |
| 원경 | 시점을 따라다니는 배경 도시 210조각 |
| 실내 | 건물마다 출입구 보장 · 지붕 아래에서 안개/입자/바람 감소 |
| 이야기 | 3막 10편. 2막은 정착지가, 3막은 되살린 흙이 연다 — 회차를 거듭할수록 드러난다 |
| 종자고 | 분화구 언저리에 처음부터 서 있다. 열 편을 다 읽어야 열쇠가 밝혀진다. 1,204종 |
| 첨탑 | 셋. 걸어서 8초를 올라가면 반경 46m 의 흙과 단말이 나침반에 박힌다. 죽어도 남는다 |
| 온실 | (70, −30) 무너진 재배동. 흙 22·풀 16 이 몰려 있다. 초록 유리로 발견하고 `溫` 표지로 돌아온다. 매 생 새것 |
| 급수탑 | (−34, 62) 터진 물탱크가 다리 위에 주저앉아 있다. 집수반에 빗물 26. 오를 수는 없다 |
| 격납고 | (26, 72) 앞이 통째로 열린 정비동. 잔해 30. **등급과 무관하게 낮에 로봇이 깬다** (반경 34m) |
| 체온 | 밤·비·먼지폭풍에 떨어지고 해·불·지붕이 되돌린다. 35에서 떨고 0에서 죽는다 |
| 포자병 | 노출이 쌓여 발병 → 감속·허기 가중·회복 차단. 따뜻하고 배부르면 스스로 낫는다 |
| 화톳불 | 네 가지 이유 — 막고, 덥히고, 끓이고, 굽는다. 대신 마른 풀을 먹여야 탄다 |
| 연료 | 마른 풀덤불 58곳(비옥한 땅에만) + 수확할 때 나오는 작물 대 |
| 건설 | 방벽이 **옆 칸을 보고 알아서 돌아서고**(R로 덮어쓰기), 문으로 드나들고, `X` 로 철거한다 |
| 요리 | 구운 보리 · 보리죽 · 끓인 물. **불 앞을 7~16초 지켜야** 되고, 불이 꺼지면 중단된다 |
| 도감 | 식물 · 조리 · 땅과 계절 세 갈래. 작물 이름은 재생종 보리 |
| 퇴비 | 유기물을 삭혀 흙으로. 키운 것을 되돌린다 |
| 플랜트 | 잔해를 흙으로. **부순 것**을 되돌린다. 종자고를 연 사람만 만든다. 도는 동안 18m 안이면 등급과 무관하게 낮에 로봇이 깬다 |
| 계절 | 해빙·건기·포자철·혹한 (15일씩). 체온·포자·성장·날씨·풀 재생을 저마다 다르게 |
| 악화 곡선 | 포자 농도가 해마다 오르고, 되살린 흙이 도로 끌어내린다. HUD에 나란히 뜬다 |
| 정착지 | 다섯 등급. 두른 넓이를 격자 물 흘리기로 잰다 — 개수로는 통과하지 못한다 |
