## 플레이 피드백 (2026-08-30) — v0.3.1 **처리 완료**

실제로 플레이해 보고 나온 것들. **기능을 더 얹기 전에 여기부터 비운다.**
새 시스템을 열 개 더 넣어도 보관함이 안 열리면 아무 소용이 없기 때문이다.

**버그 — 이미 있는 것이 망가진 것**

| | 증상 | 원인 |
|---|---|---|
| B1 | **보관함이 열리지 않는다** | 세이브를 불러올 때 `Buildings.restore` 가 보관함의 내용물 객체를 만들지 않았다. 설치물은 살아나는데 그 안이 없다 — **넣어둔 물건도 함께 사라지고 있었다** |
| B2 | 조감도를 읽은 뒤 기록 창이 닫히지 않는다 | 창에 닫기 버튼도 안내 문구도 없다. 키를 아는 사람만 닫을 수 있었다 |
| B3 | 가방과 보관함에 같은 물건이 나뉘어 쌓이고 합쳐지지 않는다 | 넣을 때만 기존 더미를 채운다. 한 번 쪼개지면 다시 합칠 방법이 없었다 |
| B4 | 물건을 버릴 수 없다 | 버리기(`Q`)가 **핫바에 배정된** 칸만 본다. 배정되지 않은 물건은 손도 댈 수 없다 |
| B5 | 보관함 칸이 한자로만 보인다 | 가방은 SVG 아이콘으로 바꿨는데 보관함 창만 옛 코드로 남아 있었다 |

**설계 구멍 — 있어야 하는데 없는 것**

| | 내용 |
|---|---|
| D1 | **방벽을 한 방향으로만 세울 수 있다.** 판이 항상 같은 축을 보고 서서, 이어 놓으면 벽이 아니라 울타리가 된다 → 구역을 두를 수 없다 |
| D2 | **문이 없다.** 둘러싸면 자기도 못 들어간다. 여닫을 수 있는 출입구가 있어야 방벽이 쓸모를 얻는다 |
| D3 | **철거가 없다.** 잘못 놓으면 영영 그대로다. 자재도 돌려받지 못한다 |
| D4 | **핫바 안에서 자리를 못 바꾼다.** 가방에서 배정만 할 수 있고, 1번과 3번을 맞바꾸려면 둘 다 다시 배정해야 한다 |
| D5 | **작물에 이름이 없다.** "기초 작물"은 이름이 아니라 분류다. 무엇을 심고 있는지 모른 채 농사를 짓는다 |
| D6 | **요리가 없다.** 수확물을 그대로 씹는 것 말고 할 일이 없다 — 농사의 보상이 한 겹뿐이다 |

**D5·D6의 해법은 하나로 묶었다.** 시작 가방에 **식물 도감**을 넣는다.
주인공은 보존 구역에서 농사를 짓던 사람이니 도감을 가지고 나온 것이 자연스럽고,
기억을 잃은 플레이어에게 "이 작물은 무엇이고 어떻게 먹는가"를 설명할 자리가 생긴다.
튜토리얼을 안내문이 아니라 **소지품**으로 주는 셈이다.

**처리 결과**

| | 어떻게 고쳤나 |
|---|---|
| B1 | `restore` 가 보관함 내용물 객체를 만들도록 했다. 이걸 놓치면 껍데기만 살아나고 저장된 물건이 사라진다 |
| B2 | 기록·도감 창에 닫기 버튼과 안내 문구를 달고, 바깥을 눌러도 닫히게 했다 |
| B3 | `compact()` — 옮기고 나면 양쪽 다 조각난 더미를 앞칸부터 합친다. 마모도가 있는 도구는 개체가 구분되어야 하므로 건드리지 않는다 |
| B4 | 칸 번호로 직접 버리는 `dropAt()`. 가방과 보관함 칸 모두에 × 버튼과 오른쪽 버튼을 달았다 |
| B5 | 설명 상자를 `ItemTip` 으로 빼내 가방과 보관함이 함께 쓴다. 칸을 그리는 곳이 둘이면 설명도 둘이 된다 |
| D1 | `Placed.rot` — `R` 로 축을 돌린다. 충돌은 칸 전체라 모서리에 틈이 생기지 않는다 |
| D2 | `gate` 설치물. 열면 충돌이 빠지고 닫으면 벽과 같다. 생물은 열지 못한다 |
| D3 | `X` 를 **누르고 있으면** 철거된다. 자재는 전액 환급. 한 번 누르는 것으로 뜯기면 애써 키운 밭이 손가락 하나에 사라진다 |
| D4 | 번호 칸을 눌러 집고, 다른 칸을 눌러 맞바꾼다 |
| D5·D6 | 작물 이름을 **재생종 보리**로 짓고, 식물 도감과 화톳불 요리 둘(구운 보리 · 보리죽)을 넣었다 |
