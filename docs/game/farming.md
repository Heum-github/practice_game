## 농사 — 어디에 짓느냐가 전부다

밭은 한 칸씩 아무 데나 놓는 대신 **3×2 구획을 통째로** 놓는다.
좌클릭 전에 미리보기가 뜨고, 칸마다 색으로 상태를 보여준다.

| 색 | 뜻 |
|---|---|
| 진한 초록 | 비옥한 땅 — 빨리 자라고 많이 거둔다 |
| 옅은 초록 | 겨우 기준을 넘긴 땅 |
| 붉은색 | 놓을 수 없다 (흙 부족 · 이미 점유 · 고르지 않은 땅) |

| 비옥도 | 다 자라는 데 | 수확량 |
|---|---|---|
| 34% (최소) | 20.8분 | 2 |
| 70% | 16.0분 | 3 |
| 100% | 13.4분 | 4 |

좋은 땅은 시간당 약 세 배를 낸다. 그래서 **좋은 땅을 찾아다니는 일 자체가 플레이**가 된다.
구획은 격자에 붙고 놓일 때 땅을 평평하게 다지므로, 여러 개를 이어 놓으면 저절로 줄이 선다.

## 퇴비 — 흙이 늘어나는 유일한 순간

지금까지 흙은 유한했다. 세상에 놓인 31곳을 다 캐면 농장은 거기서 멈추고,
"농사와 탐험이 하나의 루프로 묶인다"던 설계가 막다른 길이 된다.

퇴비 더미가 그 벽을 연다. 마른 풀과 알곡을 넣고 며칠 두면 **흙이 다시 나온다.**

| | |
|---|---|
| 넣는 것 | 마른 풀 1몫 · 재생종 보리 2몫 (`E`) |
| 한 번에 | 6몫까지 |
| 삭는 데 | 한 몫에 1.4일 (약 21분) |
| 나오는 것 | 흙 1 — 최대 4까지 쌓아둔다 |
| 해금 | 조감도 ([기획 3.2](../design/03-systems.md)의 "중반 기술 목표") |

즉석 변환이 아니라 며칠 걸리는 설비인 이유가 있다. 레시피 한 줄이면 흙은 그냥
작물의 다른 이름이 되지만, 시간이 걸리면 **미리 넣어두는 살림**이 된다.

그리고 알곡을 넣으면 두 배로 삭으므로, 매번 **"지금 먹을 것인가, 밭을 넓힐 것인가"**
를 저울질하게 된다 — 흙이 유한하던 시절에는 없던 선택이다.
좌하단 `삭은 흙 n` 칩이 꺼낼 것이 있는지 알려준다.
