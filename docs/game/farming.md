# 농사

이 게임의 심장이다. 그런데 지금은 심장이 뛰지 않는다.
아래는 **왜 그런지를 숫자로 적은 것**과, 그 다음에 무엇을 할지다.

---

## 1. 지금 — 한 칸이 요구하는 것

밭은 **한 칸씩** 놓는다 (`FARM.bedWidth = 1`).
좌클릭 전에 미리보기가 뜨고 칸 색이 그 땅의 비옥도를 알려준다.

> 이 문서는 오랫동안 "3×2 구획을 통째로 놓는다"고 적어 두었으나 **사실이 아니다.**
> 코드는 v0.3부터 한 칸씩이었다. 이번에 바로잡는다.

| 색 | 뜻 |
|---|---|
| 진한 초록 | 비옥한 땅 — 빨리 자라고 많이 거둔다 |
| 옅은 초록 | 겨우 기준(34%)을 넘긴 땅 |
| 붉은색 | 놓을 수 없다 (흙 부족 · 이미 점유 · 고르지 않은 땅) |

### 한 번의 수확에 드는 것

성장 배수 = `0.62 + 비옥도 × 0.72`, 다 자라는 데 `1.2일 ÷ 배수`.
수확량 = `round(1.0 + 비옥도 × 2.6)`. 하루는 실시간 15분이다.

| 비옥도 | 다 자라는 데 | 수확량 | 필요한 급수 |
|---|---|---|---|
| 34% (놓을 수 있는 최소) | 1.39일 = **20.8분** | 2 | **3회** |
| 50% | 1.22일 = 18.4분 | 2 | 2회 |
| 70% | 1.07일 = 16.0분 | 3 | 2회 |
| 100% | 0.90일 = **13.4분** | 4 | 2회 |

급수 횟수는 계산해서 나온 값이다 — 한 번 주면 0.62일치가 차고
(`moisturePerWatering`), 그 이상 겹쳐 담기지 않는다(`moistureMax 0.9`).
문서와 주석은 오랫동안 "대략 두 번"이라 적었지만, **34% 땅에서는 세 번**이고
건기(`dry 1.5`)에는 네 번, 먼지폭풍 한복판(×3.6)에서는 아홉 번이다.

### 조작 수 · 결정 수 · 실패 지점

| | 개수 | |
|---|---|---|
| 한 주기의 조작 | **4~5** | 심기 1 · 급수 2~3 · 수확 1 (+ 최초 1회 일구기) |
| 누르고 있는 시간 | **3.5초** | `plantTime 0.7 + waterTime 0.6×3 + harvestTime 1.0` |
| 한 주기의 **결정** | **0** | ↓ |
| **실패할 수 있는 지점** | **0** | ↓ |

**결정이 0인 이유.** 이 칸의 일생에서 플레이어가 무언가를 고르는 순간은
**놓을 자리를 정하는 한 번뿐**이고, 그것은 영원히 되돌릴 수 없으며 두 번 다시
묻지 않는다. 그 뒤로는—

- 심기 — 씨앗이 한 종류다. 고를 것이 없다.
- 급수 — 말랐으면 준다. "주지 않는 편이 나은 경우"가 없다.
- 수확 — 익었으면 거둔다. 너무 일러서도, 너무 늦어서도 손해가 나지 않는다.

**실패가 0인 이유.** 코드를 다 뒤져도 작물이 사라지는 경로가 없다.

| 잃을 뻔한 것 | 실제로는 |
|---|---|
| 물이 마른다 | 성장이 **멈출** 뿐. 며칠이 지나도 그대로 기다린다 |
| 다 익은 채로 둔다 | `stage === 'ripe'` 는 `update()` 가 아예 건너뛴다. **영원히 썩지 않는다** |
| 혹한이 온다 | 성장 ×0.35. 느려질 뿐 죽지 않는다 |
| 포자 농도가 오른다 | 몸과 도구에만 걸린다. **밭에는 아무 항도 없다** |
| 생물·로봇이 온다 | 작물을 건드리는 코드가 없다 |
| 연작 | `plot.fertility` 는 놓을 때 지형에서 한 번 읽고 **다시는 바뀌지 않는다** |

마지막 줄이 특히 아프다. 기획서 3.4는 "연작 시 하락, 퇴비·휴경으로 회복"이라고
**적어 두고 구현하지 않았다.** [알려진 한계](limits.md)의 첫 줄이 그것이다.

### 첫 수확과 스무 번째 수확의 차이

셋뿐이고, **셋 다 플레이어가 밭에 한 일이 아니다.**

1. **계절** — 성장 ×0.35~1.15, 마름 ×0.6~1.5. 같은 칸이 3.3배까지 흔들린다
2. **종자고** — 성장 ×1.3 · 수확 +1. 이야기가 끝나면 한 번 붙고 끝
3. **생존자** — 등급 2부터 급수와 파종을 대신한다

3번이 방향을 거꾸로 돌린다. 생존자 하나는 26초마다 집안일을 하나 하니 **하루 34.6회**,
넷이면 138회다. 밭 14칸을 다 덮고도 남는다. 즉 **거점이 커질수록 밭에서 할 일이
줄어든다.** 스무 번째 수확은 첫 번째보다 손이 덜 간다.

### 그리고 저울이 두 곳에서 새고 있다

**하나 — 씨앗은 늘지도 줄지도 않는다.** `seedYield = 1`이라 심은 만큼 정확히 돌아온다.
씨앗은 세상 어디에서도 나오지 않는다. 시작 6개, 종자고 30개, 그게 전부다.
**종자고를 열기 전까지 한 번에 심을 수 있는 밭은 영원히 6칸**이고,
이 숫자를 화면 어디에서도 알려주지 않는다.

**둘 — 그런데 생존자는 씨앗 없이 심는다.** `Settlers.doChore()` 는 빈 밭에
`stage = 'planted'` 를 그냥 쓴다. 가방을 보지 않는다. 수확하면 씨앗 1이 나오므로
**등급 2부터 씨앗은 무한이 된다** — 14칸이면 하루 11개씩 불어난다.
6칸 천장과 무한 분수가 등급 하나를 사이에 두고 붙어 있다. 둘 다 설계가 아니다.

### 땅이 모자란 것은 아니다

| | |
|---|---|
| 세상의 흙 자리 | 31곳 + 온실 22곳 = 53곳 |
| 한 자리에서 나오는 흙 | 2~4회 × 1 ≈ 2.7줌 |
| 합계 | **약 144줌 = 밭 144칸** (퇴비·플랜트는 빼고) |
| 최고 등급이 요구하는 밭 | **14칸** |

퇴비를 켜기도 전에 세계가 최고 등급의 열 배를 쥐여준다.
**밭을 넓히는 것은 이미 자원 문제가 아니다.** 넓히지 않는 이유는 흙이 없어서가 아니라
넓혀도 달라지는 것이 없어서다. 여기를 틀리면 아주 잘 푼 틀린 문제가 된다.

---

## 2. 진단 한 줄

> **밭은 놓는 순간이 완성이고, 그 뒤로 이 땅에 대해 물어보는 질문이 하나도 없다.**

기다림은 있고 결정은 없다. 잃을 것이 없으니 지켜낸 보람도 없다.
그래서 다음 셋을 넣는다 — **하나는 땅, 하나는 위협, 하나는 씨앗.**

---

## 3. 넣을 것 셋

셋 다 이미 있는 것에 걸린다. 혼자 도는 새 게이지는 없다.

| | 무엇 | 무엇에 걸리는가 |
|---|---|---|
| ① | **땅심** — 밭 칸의 비옥도가 변한다 | 비옥도 · 퇴비/플랜트 |
| ② | **시듦** — 밭이 죽는다 | 물 · 계절 · 날씨 · 포자 농도 · 화톳불 |
| ③ | **종자 계통** — 내 보리가 좋아진다 | 땅심 · 종자고 |

### ① 땅심 — 갓 일군 땅과 세 해를 부친 땅

`plot.fertility` 를 상수에서 **변수로** 바꾼다. 지형이 출발점을 정하고,
그 뒤는 사람 손이 정한다.

| 언제 | 얼마나 | 천장 |
|---|---|---|
| 거둘 때마다 | **−0.06** | — |
| 빈 채로 쉬게 두면 (휴경) | **+0.02 / 일** | **지형이 준 원래 값까지만** |
| 흙 한 줌을 부으면 (퇴비·플랜트 산출) | **+0.12** | **1.0 까지** |
| 시들어 죽으면 | **−0.05** | — |
| 하한 | 0.10 | 심는 것을 막지는 않는다 |

**자연은 원래대로만 돌려놓고, 그 위로는 사람이 올린다.** 이 한 줄이 2번 질문의 답이다.
개척의 재미를 "칸이 늘어난다"에 두면 이미 남는 흙 144줌 앞에서 무의미해진다.
**"이 땅이 좋아진다"**에 두어야 값을 한다.

계산해 보면 휴경만으로는 못 버틴다. 한 번 거두는 데 1.2일이 걸리고 그때 −0.06인데,
휴경은 그 −0.06을 갚는 데 3일이 든다. **답은 퇴비다.** 흙 한 줌은 새 밭 한 칸이기도 하므로
매 줌마다 묻게 된다 — **새 칸을 열까, 있는 칸을 되살릴까.**
"먹을 것인가 넓힐 것인가"였던 저울이 셋이 된다.

되살림 지수(3.7)와 겹치지 않는다. 퇴비에서 흙을 **꺼낼 때** 이미 한 번 세었고,
그 줌을 어디에 쓰는지는 세계가 상관하지 않는다. 새 장부는 없다.

**곡선 다시 재기.** 땅심이 0.10~1.00을 오가게 되면 지금의 성장·수확 식은 폭이 너무 좁다
(속도 1.55배 · 수확 2단계). 값만 다시 잡는다 — 새 키가 아니라 **기존 키의 값**이다.

| 키 | 지금 | 제안 |
|---|---|---|
| `growthFertilityBase` | 0.62 | **0.42** |
| `growthFertilityScale` | 0.72 | **1.10** |
| `yieldFertilityBase` | 1.0 | **0.9** |
| `yieldFertilityScale` | 2.6 | **3.2** |

| 땅심 | 다 자라는 데 | 수확 | 낟알 하나당 |
|---|---|---|---|
| 0.15 (버려둔 땅) | 2.05일 = 30.8분 | 1 | 30.8분 |
| 0.34 (갓 일군 최소) | 1.51일 = 22.7분 | 2 | 11.4분 |
| 0.50 | 1.24일 = 18.6분 | 3 | 6.2분 |
| 0.70 | 1.01일 = 15.1분 | 3 | 5.0분 |
| 0.85 (퇴비를 부어온 땅) | 0.87일 = 13.0분 | 4 | 3.3분 |
| 1.00 | 0.79일 = **11.8분** | 4 | **3.0분** |

시간당 산출의 폭이 **3.1배에서 10.4배로** 벌어진다.
그러면서 1일차는 그대로다 — 첫 밭이 놓이는 0.5~0.7 구간은 지금과 ±0.5분 안이다.
**바닥과 천장만 열고 출발점은 건드리지 않는다.**

> 이 네 값은 **땅심과 함께** 들어가야 한다. 먼저 넣으면 34% 땅이 20.8분에서
> 22.7분으로 느려지기만 하고 얻는 것이 없다. 그래서 지금 고치지 않았다.

**읽히는 법.** 놓인 밭도 미리보기와 **같은 초록 램프**를 쓴다
(`Buildings.updateGhost` 에 이미 있는 그 식). 지금 밭 인스턴스에는 색이 없고
미리보기에만 있다 — 같은 코드를 놓인 밭에도 쓰면 끝난다.
땅이 여위면 눈에 보이게 옅어져야 한다.

### ② 시듦 — 잃을 수 있어야 지켜낸 보람이 있다

밭 칸마다 `wilt` 0..1 하나. 스트레스를 받으면 오르고, 돌봐 주면 내린다.
**세 가지가 이 값을 밀어 올리는데, 셋 다 이미 있는 것들이다.**

| 무엇 | 오르는 속도 | 죽기까지 |
|---|---|---|
| **마름** — 물이 0인 채 방치 | `0.5 × 마름배수 / 일` | 평시 2일(30분) · 건기 1.33일(20분) · 폭풍 속 0.55일(8분) |
| **서리** — 혹한기 밤(`daylight ≤ 0.34`) | `0.9 / 일` | **밤 세 번** |
| **포자** — 농도가 1.4를 넘은 초과분 | `(농도 − 1.4) × 0.35 / 일` | 천장(2.6)에서 2.4일 |
| 회복 — 물이 있고 스트레스가 없으면 | `−1.2 / 일` | 물 한 번이면 반나절 만에 가신다 |

`wilt ≥ 1` 이면 **작물이 죽는다** — 밭이 비고, 씨앗을 잃고, **땅심이 −0.05** 된다.
방치는 두 번 값을 치른다.

**세 가지를 고른 이유가 각각 다르다.**

- **마름**은 지금 있는 "성장 정지"를 위험으로 바꾼다. 새 값이 하나도 필요 없다 —
  `dryMult`(계절 × 먼지폭풍)가 이미 그 시계를 돌리고 있고, 지금은 그 시계가
  아무것도 재지 않을 뿐이다. 회복이 빠른 것이 요점이다: **죽는 것은 늦은 밭이 아니라
  잊은 밭이다.** 돌아와서 물을 주면 거의 언제나 산다.
- **서리**는 계절에 처음으로 이빨을 준다. 혹한기에 심는 사람은 지금도 없다(성장 ×0.35).
  이건 심는 판단이 아니라 **거두는 판단**이다 — 계절이 바뀌기 전에 걷을 것인가.
  계절 알림은 이미 뜬다.
- **포자**는 기획서 3.4와 3.7이 둘 다 약속해 놓고 아직 없는 "노지 재배 불가"를
  **점진적으로** 가져온다. 그리고 이것이 처음으로 **되살림을 밭에 직접 걸어 준다** —
  지금까지 되살린 흙은 몸과 도구만 지켰다. 두 곡선의 경주가 농사 안으로 들어온다.

**그런데 서리에는 오늘 쓸 수 있는 답이 있어야 한다.** 없는 벌은 벌이 아니라 저주다.
지붕과 밀폐 온실은 v0.6의 아직 안 된 조각이니, 지금 있는 것으로 답한다 —
**화톳불이 반경 6.5m 안의 밭에서 서리를 막는다.**

새 시스템이 아니라 이미 선 물건에 붙는 네 번째 이유다
(생물을 막는다 · 몸을 덥힌다 · 물을 끓인다 · **밭을 지킨다**).
연료를 채워 둘 이유가 하나 늘고, 화톳불 배치가 밭 배치와 얽힌다.
그리고 **발견 경로가 저절로 생긴다** — 혹한이 지나간 아침에 불 곁의 밭만
초록으로 남아 있으면 아무도 설명해 줄 필요가 없다.

**읽히는 법.** 시드는 작물은 갈색으로 간다 (땅심의 초록 램프와 같은 채널).
시드는 밭이 하나라도 있으면 좌하단에 `시드는 밭 n` 칩 — `삭은 흙 n` 과 같은 자리, 같은 방식.
죽는 순간에는 알림을 띄운다. **무엇을 잘못했는지가 화면에서 읽혀야 한다.**

**생존자와의 관계가 요점이다.** 생존자는 급수를 하므로 마름을 막아 준다.
서리도 포자도 막지 못하고, 퇴비를 붓지도 갈무리를 하지도 않는다.
즉 **거점이 커지면 물 걱정은 사라지고 땅심과 계통은 여전히 내 몫**이다.
"밭이 커질수록 할 일이 준다"가 여기서 뒤집힌다.
그리고 자리를 오래 비울 수 있게 해 주는 것이 가방이 아니라 **거점**이다 — v0.3의 규칙 그대로다.

### ③ 종자 계통 — 첫 개량종

다 자란 밭 앞에서 **거두는 대신 갈무리한다** (`E` 길게, 2.6초).
작물을 얻지 않고 **씨앗 3**을 얻는다. 그리고 그 밭의 땅심이 다음 단계의
문턱을 넘었으면 **계통이 한 단계 오른다.**

계통은 밭 하나가 아니라 **농장 전체에 걸리는 값 하나**다.
아이템이 아니라 `Environment.restored` 와 같은 모양의 숫자다.

| 단계 | 필요한 땅심 | 성장 | 수확 |
|---|---|---|---|
| 0 | — | ×1.00 | +0 |
| 1 | 0.55 | ×1.06 | +0.15 |
| 2 | 0.70 | ×1.12 | +0.30 |
| 3 | 0.82 | ×1.18 | +0.45 |
| 4 | 0.92 | ×1.24 | +0.60 |
| 5 | 1.00 | **×1.30** | **+0.75** |

수확 보너스는 `round` **앞에** 더한다. 그래야 계단이 뚝뚝 끊기지 않고,
"이번 밭은 하나 더 나왔다"가 자주 일어난다.

**대가가 분명하다.** 다 자란 밭 하나를 통째로 포기한다 (작물 3~4개, 한 끼 반).
그리고 첫 단계조차 땅심 0.55를 요구하므로 **퇴비를 부어 키운 밭이라야 한다.**
셋이 한 줄로 꿰인다 — **퇴비 → 땅심 → 계통.**

**종자고를 이 사다리의 꼭대기로 옮긴다.** 지금 종자고는 성장 ×1.3 · 수확 +1을
따로 들고 있는데, 계통 5단계와 하는 일이 똑같다. 두 개를 두는 대신
**문을 열면 계통이 5단계가 된다**(그리고 씨앗 30). 특례가 하나 늘지 않고 하나 준다.
1,204종이 곧 가장 좋은 종자라는 뜻이라 이야기와도 맞고, 밭을 부쳐 온 사람은
이미 4단계로 도착하므로 종자고가 **갑자기 세지는 물건이 아니라 하던 일의 끝**으로 읽힌다.

**계승.** 계통은 손에 있던 것이므로 **죽으면 잃는다.** 다만 종자고를 연 사실은
이미 유산이므로, 한 번 연 사람은 다음 생에도 5단계에서 시작한다.
새 규칙이 아니라 [있는 규칙](legacy.md)이 그대로 적용된 것이다.

## 4. 안 하는 것과 그 이유

이 목록이 설계의 절반이다.

| 안 한다 | 왜 지금이 아닌가 |
|---|---|
| **작물 종류 추가** | 종류가 하나인 게 문제가 아니다. 둘로 늘려도 결정은 "무엇을 심을까" 한 번이고 표를 외우면 끝난다. **땅심이 먼저 있어야** 두 번째 작물이 "이 땅에 무엇이 맞는가"라는 질문이 된다. v0.7 |
| **병해충** | 시듦과 같은 자리를 두 번 채운다. 죽는 이유가 둘이면 화면에서 어느 쪽인지 읽히지 않고, 실패가 판단이 아니라 사고가 된다 |
| **비료 등급** | 지금의 저울은 "이 한 줌을 새 칸에 쓸까 있는 칸에 쓸까"다. 등급을 나누면 "어떤 비료를 쓸까"가 생기는데 그건 표 고르기지 저울질이 아니고, 원래 저울을 흐린다 |
| **트랙터·자동화** | 자동화는 이미 과하다. 생존자가 급수와 파종을 다 가져가서 밭이 커질수록 할 일이 준다. 더 넣을 게 아니라 이번에 **그 구멍을 막아야 한다** |
| **관개 (물길·수로)** | 지표수가 없는 세계라는 전제와 정면으로 부딪친다. 그 자리는 집수기와 급수탑의 것이다 |
| **밭 구획 키우기 (3×2)** | 클릭 수가 줄 뿐 결정 수는 그대로다. 지금 문제는 클릭이 많아서가 아니다 |
| **수경·양액** | 밀폐 온실(v0.6 남은 조각)의 몫이다. 시듦의 포자 항이 그 문을 미리 열어 둔다 |
| **성장 시간 늘리기** | 기다림은 어려움이 아니라 지루함이다. 셋 중 어느 것도 작물을 느리게 만들지 않는다 |

## 5. 한 판의 곡선

| | 지금 | 셋을 넣은 뒤 |
|---|---|---|
| **1일차** | 흙 0으로 시작. 40m 밖으로 나가 한두 줌을 캔다. 밭 1~2칸, 씨앗 6개 중 둘을 쓴다. 물을 두세 번. 첫 수확 2개 | **같다.** 다만 첫 밤에 "마르면 죽는다"를 칩과 갈색으로 배운다. 첫 밭은 여전히 18분 언저리다 |
| **10일차** | 밭 4~6칸(씨앗이 6개라 더 못 심는다). 퇴비 한 통이 돌기 시작. 등급 2가 오르면 급수와 파종이 사라진다. 남은 일은 수확 버튼 | 밭 5~6칸인데 **둘은 이미 0.34까지 여위었다.** 퇴비 첫 줌 앞에서 처음으로 묻는다 — 새 칸인가 되살림인가. 건기가 오면 자리를 비우는 일이 계산이 된다. 생존자가 물을 맡아도 **땅심은 내 몫이다** |
| **40일차** | 밭 14칸. 생존자 넷이 다 돌본다. 열네 칸이 1일차의 그 칸과 똑같다. 하는 일: 수확 | 밭 14칸이 **같지 않다.** 퇴비를 계속 부은 서넛은 0.85 이상에서 4개씩 내고(3.3분/낟알), 나머지는 0.4대에서 2개씩 낸다(11분/낟알). 혹한 전에 무엇을 걷을지 고른다. 불 곁 칸만 겨울을 난다. 계통 3~4단계. 종자고가 그것을 5로 올린다 |

**희열은 어디에 오는가** (1번 질문).
첫 수확이 아니다 — 그건 20분 기다린 값이지 해낸 값이 아니다.
**첫 개량종이다.** 그 앞에 네 가지가 있어야 한다:
좋은 땅을 찾아 놓고(기존) · 퇴비를 부어 0.55를 넘기고(①) · 시들지 않게 지켜내고(②) ·
다 자란 것을 먹지 않고 포기한다(③). 넷을 다 한 사람에게만 온다.
그리고 보상이 그 칸 하나가 아니라 **농장 전체**에 걸리므로 다음 수확부터 눈에 보인다.

두 번째 자리는 **되살려낸 밭**이다. 여위어 낟알 하나가 30분씩 걸리던 칸에
퇴비를 세 줌 붓고 며칠 쉬게 해서 다시 4개를 낼 때 —
이건 ②가 있어야만 성립한다. **긴장 없이는 안도도 없다.**

## 6. 먼저 막을 구멍 (시스템이 아니라 버그)

셋을 얹기 전에 씨앗 저울부터 고쳐야 한다. 지금 두 값이 한 칸도 안 되는 거리에서 모순이다.

1. **생존자가 씨앗 없이 심는다** — `Settlers.doChore()` 가 가방을 보지 않는다.
   가방(또는 보관함)의 씨앗을 쓰고, 없으면 심지 않게 한다.
2. **씨앗은 갈무리로만 늘어난다** — 위를 고치면 `seedYield = 1` 이 정확히 보존이 되고,
   씨앗이 느는 유일한 길은 ③이 된다. 먹을 것을 포기해야 씨가 는다.
   6칸 천장은 그렇게 열린다.

## 7. 퇴비 — 흙이 늘어나는 순간 (그대로)

마른 풀과 알곡을 넣고 며칠 두면 흙이 나온다.

| | |
|---|---|
| 넣는 것 | 마른 풀 1몫 · 재생종 보리 2몫 (`E`) |
| 한 번에 | 6몫까지 |
| 삭는 데 | 한 몫에 1.4일 (약 21분) |
| 나오는 것 | 흙 1 — 최대 4까지 쌓아둔다 |
| 해금 | 조감도 ([기획 3.2](../design/03-systems.md)) |

즉석 변환이 아니라 며칠 걸리는 설비인 이유가 있다. 레시피 한 줄이면 흙은 그냥
작물의 다른 이름이 되지만, 시간이 걸리면 **미리 넣어두는 살림**이 된다.

**①이 들어가면 퇴비에 두 번째 사는 이가 생긴다.** 지금까지 흙 한 줌은
새 밭 한 칸이라는 쓸모뿐이었고, 세상에 남는 흙이 144줌이라 사실 급하지 않았다.
땅심이 들어가면 같은 한 줌이 **있는 밭을 되살리는 데도** 쓰인다.
좌하단 `삭은 흙 n` 칩이 꺼낼 것이 있는지 알려준다.

## 8. 팀장에게 — `src/config.ts` 의 `FARM` 에 넣어 주실 키

값은 위 표에서 뽑은 것이다. 구조는 팀장 몫이라 코드를 고치지 않았다.

```ts
// ── ① 땅심 (기획서 3.4) — 비옥도가 상수에서 변수가 된다
/** 하한. 여기까지 여위어도 심는 것을 막지는 않는다 — 느리고 적을 뿐이다 */
fertilityMin: 0.1,
/** 사람 손으로 올릴 수 있는 천장. 자연 회복은 지형이 준 값까지만이다 */
fertilityMax: 1.0,
/** 한 번 거둘 때마다 깎이는 몫 (연작) */
fertilityPerHarvest: 0.06,
/** 빈 채로 쉬게 두면 하루에 도로 오르는 몫 (휴경). 원래 값을 넘지 못한다 */
fertilityFallowPerDay: 0.02,
/** 흙 한 줌을 부으면 오르는 몫. 이것만이 원래 값 위로 올린다 */
fertilityPerCompost: 0.12,

// ── ② 시듦 (기획서 3.4 · 3.7) — 밭이 죽는 유일한 길
/** 물이 0인 채로 방치될 때 하루에 쌓이는 몫. dryMult 가 곱해진다 */
wiltDryRate: 0.5,
/** 혹한기 밤(daylight ≤ 0.34)에 하루당 쌓이는 몫 */
wiltFrostRate: 0.9,
/** 포자 농도가 이 값을 넘으면 그 초과분이 시들게 한다 */
wiltSporeSafe: 1.4,
wiltSporeRate: 0.35,
/** 물이 있고 스트레스가 없을 때 하루에 가시는 몫 */
wiltRecover: 1.2,
/** 시들어 죽은 자리의 땅이 잃는 몫 */
wiltDeathFertility: 0.05,
/** 화톳불이 서리를 막아 주는 반경 (m) — 불의 네 번째 이유 */
frostShelterRadius: 6.5,

// ── ③ 종자 계통 (기획서 3.4 · 3.8) — 농장 전체에 걸리는 값 하나
/** 갈무리에 걸리는 시간 (s). 거두기(1.0)보다 길어야 고르는 일이 된다 */
keepTime: 2.6,
/** 갈무리로 얻는 씨앗 — 작물은 얻지 않는다 */
keepSeeds: 3,
/** 각 단계로 오르는 데 필요한 그 밭의 땅심 */
strainNeed: [0, 0.55, 0.7, 0.82, 0.92, 1.0],
/** 단계마다 붙는 성장 배수와 수확량 (수확은 round 앞에서 더한다) */
strainGrowthPerStep: 0.06,
strainYieldPerStep: 0.15,
```

**값만 바꾸는 것** (기존 키. ①과 **함께** 들어가야 한다 — 먼저 넣으면 느려지기만 한다):

| 키 | 지금 | 바꿀 값 |
|---|---|---|
| `growthFertilityBase` | 0.62 | 0.42 |
| `growthFertilityScale` | 0.72 | 1.10 |
| `yieldFertilityBase` | 1.0 | 0.9 |
| `yieldFertilityScale` | 2.6 | 3.2 |

**`VAULT` 에서 뺄 것**: `growthMult` · `harvestBonus`.
문을 열면 계통을 5단계로 올리는 것으로 갈음한다 (특례가 하나 준다).
