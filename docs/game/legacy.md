## 죽음 — 잃는 것과 남는 것

사망은 여전히 **완전 초기화**다. 되돌릴 수 있으면 밤이 무섭지 않고, 밤이 무섭지 않으면
이 게임에 남는 것이 없다.

다만 한 해가 15시간이고 마을까지 키운 뒤에 *전부* 잃으면, 그건 긴장이 아니라
그냥 그만둘 이유다. 그래서 기준을 하나 세웠다.

> **손에 있던 것은 잃고, 머리에 남은 것과 세계에 준 것은 남는다.**

| 잃는다 | 남는다 |
|---|---|
| 물자 · 도구 · 가방 | **해독한 조감도** |
| 건물 · 정착지 · 생존자 | **읽어낸 기록 조각** |
| 날짜 · 계절 · 스탯 | **퇴비로 되살린 흙** |
| | **눈에 담아둔 일대** |
| | **열어둔 종자고** |

물자와 건물은 *당신의 것*이었으므로 함께 사라진다. 그러나 조감도와 기록은 **데이터**다 —
이 세계에서 데이터는 사람보다 오래 남고, 애초에 주인공이 폐허에서 주워 온 것이 그것이었다.

그리고 **되살린 흙은 남는다.** 그것만은 소유물이 아니라 땅에 돌려준 것이기 때문이다.
환경 악화 곡선의 상승 곡선이 한 생에서 끝나지 않고 **대를 잇는다** —
세계를 되살리는 일은 원래 한 사람이 끝낼 수 있는 일이 아니다.

```
1번째 생: 흙 24줌을 되살리고 죽는다
2번째 생: 포자 농도 0.80 → 0.57 로 시작한다   ← 앞사람이 만든 세계
```

종자고도 남는다. 여는 방법을 알았고 안의 것도 이미 손에 넣었으므로,
같은 문 앞에서 처음부터 다시 시작하면 계승이 아니라 반복이다.

죽으면 사망 화면이 잃은 것을 먼저, 남는 것을 뒤에 적는다. 다음 생의 오프닝도 달라진다 —
`2번째로 눈을 뜬다. 앞선 사람이 남긴 기록이 가방에 들어 있다.`
